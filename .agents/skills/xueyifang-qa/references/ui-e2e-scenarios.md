# UI 与跨角色端到端验收清单（由原 Playwright 测试套件提炼）

使用 `preview_*` 浏览器工具按以下清单做交互验收。操作前确保前后端已启动（`localhost:3000` 与 `localhost:8080/api`）。

## P0 核心流程

### 1. 认证、权限与登录态失效
- **登录跳转与管理员分流**：
  - 买家 `20240003` 登录 `/` 后停留在首页，无法访问 `/admin/*` 和 `/service/publish`（无发布权限应提示并拦截）。
  - 管理员 `20240001` 登录 `/admin/login` 进入 `/admin/dashboard`；若普通用户尝试登录 `/admin/login` 应提示非管理员并清理登录态。
  - 访问 `/login?redirect=https://evil.com` 登录后只跳回站内首页 `/`（防开放重定向）。
- **Token 失效与回跳**：
  - 在需要登录的页面（如 `/orders`）把 `localStorage.token` 改为无效值后刷新或触发接口请求，应只弹出一次过期提示并自动跳转 `/login?redirect=%2Forders`；重新登录后自动回到 `/orders`。
- **申请发布权限联动**：
  - 买家在个人中心提交发布权限申请 → 管理员在 `/admin/permissions` 审核通过 → 买家刷新后可打开 `/service/publish`。

### 2. 服务发布、审核、编辑与上下架
- 卖家在 `/service/publish` 发布新服务（必填校验、价格 > 0、线下交易必须选交易地点）→ 初始进入“审核中”。
- 管理员在 `/admin/services` 审核通过（或驳回并填写理由）→ 通过后买家在 `/services` 列表搜得到，详情页展示价格、库存、评价数、卖家评分。
- 卖家在 `/my-services` 下架后才能点编辑修改，保存后重新提交上架。

### 3. 担保交易闭环与钱包对账
- 买家在 `/wallet` 充值后，查看可用余额增加、交易明细 `/wallet/transactions` 新增充值记录。
- 买家下单 → 跳转确认页 `/order/confirm/:serviceId` 提交 → 支付后订单变“待发货”，买家可用余额减少、冻结金额增加、服务剩余名额扣减。
- 卖家在 `/orders/sales` 发货 → 订单变“待收货”。
- 买家在 `/orders` 确认收货 → 订单变“已完成”，买家冻结金额清零、卖家钱包余额增加、双方收到站内通知、买家可提交评价并在服务详情页看到评价。
- 买家尝试购买自己的服务 / 对已下架服务下单 → 应被拒绝并弹出明确错误。

## P1 异常、退款与纠纷联动

### 4. 退款流程
- **待发货直退**：买家对“待发货”订单申请退款 → 无需卖家操作，订单直接变“交易失败 / 已退款”，冻结金额退回买家可用余额，服务名额恢复。
- **待收货协商退款**：买家对“待收货”订单申请退款 → 订单详情显示退款申请中；卖家在 `/orders/sales` **同意** → 资金退回买家；卖家**拒绝**（必须填原因）→ 买家可继续确认收货或发起纠纷。

### 5. 纠纷仲裁
- 买家在订单详情发起纠纷（填写类型与原因）→ 订单关联纠纷入口可见。
- 管理员在 `/admin/disputes` 查看纠纷与关联订单详情 → 选择**支持买家（强制退款）**或**驳回纠纷**；支持买家后买家资金退回、订单变交易失败。

## P2 资源联动与辅助模块

### 6. 管理后台字典联动（实时生效）
- **专业管理**（`/admin/resource/professionals`）：管理员新增专业 → 注册页/个人中心专业下拉立即出现新选项（验证 `dictStore` 缓存刷新）。
- **交易地点管理**（`/admin/resource/trade-locations`）：管理员新增/修改/停用地点 → 卖家发布线下服务与买家下单选择地点时同步反映变更。
- **系统配置**（`/admin/settings`）：`REGISTER_ENABLED=0` 时访问 `/register` 应提示注册已关闭并跳回 `/login`。

### 7. 聊天、收藏、通知与统计
- **实时聊天**（`/chat`）：在服务详情页点“联系卖家”进入 `/chat/:sellerId` 发消息 → 卖家端会话列表与未读数实时更新（WebSocket）。
- **收藏**（`/services/:id` ↔ `/favorites`）：收藏/取消收藏后收藏数与个人收藏列表同步。
- **通知**（`/notifications`）：订单/审核/权限事件触发后，通知中心出现对应通知，支持单条已读与全部已读。
- **数据统计**：卖家在 `/statistics/sales` 查看销量与收入；管理员在 `/admin/dashboard` 查看核心指标与近 7 天 ECharts 折线/柱状图（确认图表正常渲染且无控制台报错）。
